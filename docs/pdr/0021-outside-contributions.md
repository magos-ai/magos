# 0021 Built in public, with no code from outside yet

- Status: accepted
- Level: project
- Date: 2026-11-27

## Decision

- Magos is built in public to bring in people. Until the rules of #44
  are written, code from outside is not taken, and the README says so;
  ideas and bugs are welcome in issues.
- `CONTRIBUTING.md`, `SECURITY.md` and the rule for outside changes
  come when the first person from outside comes, or before the first
  release for other people (#44). The rule follows the line of PDR
  0001: what one person needs belongs to the open core; a function for
  a team or a hosted cloud is an add-on, and its code does not come
  into this repository.

## Rests on

- The owner's choice on 2026-11-26 (#40).

## Revisit when

The first person from outside offers code, or the first release for
other people is planned (#44).
