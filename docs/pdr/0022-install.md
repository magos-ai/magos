# 0022 One download, with no setup at the first start

- Status: accepted
- Level: project
- Date: 2026-11-27

## Decision

After the app is signed for other people (#33), Magos ships as one
download: one DMG with the app and its helper, updates that reach the
app by themselves, and a first start with no setup, which starts the
core, finds the harnesses and offers the first workspace (#43).

Until then, the app is built from source (#33).

## Rests on

- The owner's choice on 2026-11-26 (#40).

## Revisit when

The app goes to other people (#33).
