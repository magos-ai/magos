# 0019 Memory at three levels

- Status: accepted
- Level: project
- Date: 2026-11-27

## Decision

Agents need memory at three levels: one shared memory about the
person, one per workspace, and maybe one per project. Its form is
chosen by research (#34): Q-4 in `PRODUCT.md`.
