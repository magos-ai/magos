# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with
code in this repository.

## Layout

The repository has only `LICENSE`, `README.md` and this file for now. A
directory appears with its first code; there are no empty placeholders.

The licence is one, Apache-2.0, in `LICENSE` at the root. The repository is
the open core: a function that only a team or the cloud needs is a closed
add-on, and its code does not come here.

## Porting

Code and documents come here piece by piece from an earlier private
prototype, and only the pieces that are asked for. This repository is
public, so a ported file keeps nothing of the prototype that points back to
it: no issue, pull request or decision numbers, no branch names, no local
paths. When a file of the prototype describes code that is not here yet,
port only the part that is true here.
